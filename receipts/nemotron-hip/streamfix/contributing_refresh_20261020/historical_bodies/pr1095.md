## What this changes

- Nemotron on HIP now runs prompts in 2,048-row chunks. Before, it ran them in 512-row chunks.
- The routed experts get more rows a tile. A 512-row chunk gives each expert about 24 rows, in a tile of 128 rows. The routed fc1 and fc2 products took about half of a prefill.
- The prompt path does not change. Every prompt row runs on the prefill kernels at any row count, so its bits do not depend on where a chunk ends. The lane rounds, the decode path and the prompt cache do not change.
- The scratch arena stays at 2 GiB. A 2,048-row chunk uses 1.16 GiB of it at tp 1. Admission, the streams and the prompt cache get the same bytes as before.
- `tf-nemotron-hip-test teacher` uses the engine's chunk by default.

Family code only: `zig/src/families/nemotron/hip/engine.zig` and `zig/tests/nemotron_hip/gen.zig`. The change is one constant. It has no new host logic to test, so it adds no host test.

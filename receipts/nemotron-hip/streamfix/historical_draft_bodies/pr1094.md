## What this changes

- Lane rounds: every stream's window runs in one forward over the round's device plan. A round writes each row's keys and values into its own stream's pages and walks them with the planned decode attention ([fork #34][f34]). A row's bits do not depend on the rows it shares a round with. The Mamba-2 recurrence runs one stream at a time. The MoE layer takes all rows of the round together.
- Lane costs timed at load through `hip_serve/costs.zig` ([fork #29][f29]), as Qwen3.5 does, so the lane core can choose plain rounds over drafted ones.
- A lone stream's rounds replay from graphs cut at their collectives. Every rank votes on a recording (`hip.vote`); one decline runs every rank eagerly. Rounds with several streams run eagerly. `TF_POLICY=graphs=off` keeps every round eager.
- `tf-nemotron-hip-test decode`: the decode path teacher-forced a row at a time, for a reference to score.

Family code only: `zig/src/families/nemotron/hip*` and `zig/tests/nemotron_hip`.
